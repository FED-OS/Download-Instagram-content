# Support

Thank you for using FED-GRAM! This page collects the best ways to get help.

## Before you ask

Please check these first — most common questions are already answered:

- **[FAQ.md](FAQ.md)** — frequent questions and known quirks.
- **[CHANGELOG.md](CHANGELOG.md)** — recent fixes and known issues per release.
- **[INSTALL.md](INSTALL.md)** / **[BUILD.md](BUILD.md)** — setup and run details.
- **[usage.md](usage.md)** — how to use the app step by step.
- **Existing [Issues](https://github.com/FED-OS/FED-GRAM/issues)** — search closed issues for your error message.

## Reporting a bug

Found something broken? Open an issue using the
[Bug Report template](.github/ISSUE_TEMPLATE/bug_report.md). Include the URL
you tried (if public), the platform, the exact error text, and your OS /
Python version. Screenshots help enormously.

> ⚠️ **Do not** open issues for content that is private, deleted, or
> region-locked — FED-GRAM only works on **public** media by design.

## Requesting a feature

Want a new platform or a new capability? Use the
[Feature Request template](.github/ISSUE_TEMPLATE/feature_request.md) and
describe your use case. New platform engines are especially welcome.

## Discussions

For questions, ideas, and general chat that aren't bugs or feature requests,
use **[GitHub Discussions](https://github.com/FED-OS/FED-GRAM/discussions)**.
See [`.github/DISCUSSION_WELCOME_README.md`](.github/DISCUSSION_WELCOME_README.md)
for category guidelines.

## Contributing a fix

If you can reproduce and fix a bug yourself, PRs are very welcome — see
[CONTRIBUTING.md](CONTRIBUTING.md) for the workflow.

## Sponsor / donate

FED-GRAM is free and open source. If it saves you time, you can say thanks at
**[Ko-fi](https://ko-fi.com/YOUR_USERNAME)** — every coffee helps keep
development going. 💛

## Security reports

Security vulnerabilities must **not** be reported via public issues. See
[SECURITY.md](SECURITY.md) for the private disclosure process.

## Response expectations

This is a community-maintained project. Maintainers respond on a best-effort
basis — typically within a few days. Please be patient and respectful.
