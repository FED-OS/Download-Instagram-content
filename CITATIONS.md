# Citations

## How to cite FED-GRAM

FED-GRAM is a software project, not an academic publication, but if you
reference it in research, a blog post, or another project, please credit it.

### Preferred citation (BibTeX)

```bibtex
@software{fedgram,
  author       = {{FED-GRAM contributors}},
  title        = {FED-GRAM: A Universal Social Media Downloader},
  year         = {2026},
  url          = {https://github.com/FED-OS/FED-GRAM},
  license      = {MIT}
}
```

### Plain-text citation

> FED-GRAM contributors. FED-GRAM: A Universal Social Media Downloader. 2026.
> https://github.com/FED-OS/FED-GRAM

### In a README or project page

If FED-GRAM inspired or was used in your work, a line such as the following is
appreciated:

> Built with [FED-GRAM](https://github.com/FED-OS/FED-GRAM) (MIT).
