# Authors

This file lists the people who have contributed code or substantial creative
work to FED-GRAM. It is distinct from the contributor list GitHub generates
automatically — this is a curated, human-maintained record.

Names are listed alphabetically by surname. Add yourself in a pull request if
you've made a meaningful contribution.

## Authors

- **FED-GRAM Team** — initial concept, architecture, and primary development.
  The `downloaders/` engine package and the Streamlit UI were created by the
  core team. GitHub: [@FED-OS](https://github.com/FED-OS)

## How to add yourself

If you've contributed a new engine, a significant fix, or substantial
documentation, add an entry in a PR:

```
- **Your Name** — what you contributed. GitHub: [@yourhandle](https://github.com/yourhandle)
```

For one-line typo fixes or small docs tweaks, a PR is appreciated but an
AUTHORS entry is optional — GitHub's contributor graph already reflects it.
