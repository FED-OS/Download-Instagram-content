Features

Everything you need, nothing you don't

Built for speed, privacy, and simplicity. FED-GRAM gives you clean downloads without the bloat.

🔗

Auto Platform Detection

Paste any link — FED-GRAM figures out the platform using smart domain-label-boundary matching and routes it to the right engine automatically.

📦

Batch ZIP Downloads

Multi-item results like Instagram carousels or Reddit galleries can be grabbed as a single ZIP file with one click — no manual saving.

🍪

Optional Cookies Support

Upload a cookies.txt file for YouTube age-restricted content or bot-detected videos. Your cookies stay local — never uploaded anywhere.

🔒

Private & Local

Runs entirely on your machine. No data leaves your browser except the fetch to the source platform. Zero telemetry, zero ads, zero tracking.

🎬

All Media Types

Single images, carousels, albums, videos, GIFs, and audio — FED-GRAM handles them all with a uniform DownloadResult data model.

🧩

Pluggable Engine Architecture

Each platform has its own engine with a simple can_handle / download interface. Adding a new platform is as easy as dropping in a new file.

How It Works

Three steps. That's it.

No complicated setup, no browser extensions, no command-line gymnastics.

1

Paste a Link

Copy any URL from a supported social platform and paste it into the FED-GRAM input bar. That's all the input it needs.

2

Auto-Detect & Route

FED-GRAM identifies the platform, selects the right engine, and fetches the media — whether it's an Instagram carousel or a YouTube video.

3

Preview & Download

See a clean grid of all detected media. Download individual items or grab everything as a ZIP. Done in seconds.

Quick Start

Up and running in under a minute

Three commands. No build step. No configuration files.

# Clone the repository $ git clone https://github.com/FED-OS/FED-GRAM.git $ cd FED-GRAM # Install dependencies $ pip install -r requirements.txt # Launch the app $ streamlit run app.py # Opens at http://localhost:8501 ✨
# 1. Push this repo to GitHub # 2. Go to share.streamlit.io and sign in # with your GitHub account # 3. Click "New app" → select this repo # → set main file to app.py # 4. Click Deploy 🚀 # Your app goes live at # your-app-name.streamlit.app
# Build the image $ docker build -t fed-gram . # Run on port 8501 $ docker run -p 8501:8501 fed-gram # Or with docker-compose $ docker-compose up -d # App available at http://localhost:8501

💡 For full video support (YouTube, TikTok, Twitch), install ffmpeg — sudo apt install ffmpeg or brew install ffmpeg

FAQ

Frequently asked questions

Everything you might want to know before getting started.

Is FED-GRAM free to use? +
Yes, completely. FED-GRAM is open-source under the MIT license. You can run it locally for free, deploy it on Streamlit Community Cloud for free, or host it on your own server. There are no premium tiers, no feature gates, and no telemetry.
Does FED-GRAM store my downloads or browsing data? +
No. FED-GRAM runs entirely on your machine (or your own server). The only network traffic is the fetch to the source platform to retrieve media. Nothing is sent to any third-party server, and there is no analytics or tracking built in. Downloaded files are saved to a temporary working directory that you control.
Why do some YouTube videos fail to download? +
YouTube sometimes blocks automated requests with a bot-detection wall, especially for age-restricted or region-locked content. FED-GRAM lets you upload a cookies.txt file (exported from your browser using an extension like "Get cookies.txt") to authenticate as a real user. This bypasses most bot walls. Also ensure ffmpeg is installed for stream merging.
Can I add support for a new platform? +
Absolutely. The engine architecture is designed for extensibility. Create a new file in the downloaders/ package, implement two methods — can_handle(platform) returning a bool, and download(url, platform, dest_dir) returning a DownloadResult — then register it in the engine chain. Check the Engine Development Guide in the wiki and the add-platform-engine prompt in the prompts/ directory for step-by-step instructions.
What about private or login-required content? +
FED-GRAM can only access publicly available content. Private Instagram accounts, members-only YouTube videos (without cookies), and login-walled platforms will not work. The cookies upload feature helps with some authenticated content on YouTube, but FED-GRAM is fundamentally a public-content downloader. Always respect platform terms of service and copyright laws.
Is downloading social media content legal? +
Downloading publicly available content for personal use is generally legal in most jurisdictions, but laws vary. FED-GRAM is a tool — you are responsible for how you use it. Always respect copyright, platform terms of service, and creator rights. Do not redistribute downloaded content without permission. See the NOTICE.md and SECURITY.md files for more guidance.
What's the generic fallback engine? +
The generic_engine is always last in the engine chain and its can_handle() always returns True. It acts as a catch-all — if no specialized engine handles a URL, the generic engine tries to scrape og:image and og:video meta tags or handle direct media links. This means even unsupported platforms often yield results for single-image or single-video content.
