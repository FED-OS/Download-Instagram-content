# Discussion

This directory holds templates and archives for FED-GRAM's community
discussions. GitHub Discussions is the preferred home for Q&A, ideas, and
general chat; bug reports and concrete feature requests belong in
[Issues](https://github.com/FED-OS/FED-GRAM/issues).

See [.github/DISCUSSION_WELCOME_README.md](../.github/DISCUSSION_WELCOME_README.md)
for category guidelines.

## Files

- `welcome.md` — a welcome message / FAQ pin for new discussion participants.
- `category-templates.md` — suggested templates for common discussion types.

## Using these

If you run GitHub Discussions, pin `welcome.md` as the first thing newcomers
see. Copy templates from `category-templates.md` into the relevant category's
default body if your plan supports it.
